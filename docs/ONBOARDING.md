# Onboarding del nuovo manager

## Subentro nel campionato

Il nuovo manager prende il controllo di un club IA disponibile nella stagione
corrente. L'assegnazione parte dalla categoria più alta ancora disponibile e,
nei livelli con più gironi, favorisce il girone con meno manager umani.

Il club conserva posizione in classifica, punti, risultati già registrati e
calendario. Identità e gestione sportiva vengono invece sostituite.

La rosa IA precedente:

- viene scollegata dal club e marcata `REMOVED`;
- non entra nel normale pool degli svincolati;
- non viene eliminata dal database, così storico di partite e trasferimenti
  rimane consultabile;
- viene ritirata dai tabelloni individuali ancora in corso o sostituita, quando
  il torneo è soltanto sorteggiato, con giocatori attivi eleggibili.

Accademia, formazione, allenamento, eventi del club e operazioni di mercato
incompatibili con il subentro vengono ripuliti prima di creare la nuova rosa.

## Dotazione iniziale

- Bilancio iniziale: **€100.000**.
- Allenatore: livello 1.
- Responsabile giovani: livello 1.
- Tifosi iniziali: 0.
- Reputazione iniziale: 1.
- Rosa iniziale: **6 giocatori** creati appositamente per il manager.
- Accademia iniziale: 3 giovani, uno di 14, uno di 15 e uno di 16 anni, ciascuno
  con 3 caratteristiche stimate.

La forza della rosa iniziale dipende dalla categoria del club rilevato. I sei
profili base sono:

1. giocatore 35-45 anni, OVR base 64;
2. giocatore 35-45 anni, OVR base 65;
3. giocatore 35-45 anni, OVR base 66;
4. veterano 55-65 anni, OVR base 62;
5. giovane 20-25 anni, OVR base 60;
6. giocatore 27-36 anni, OVR base 61.

Per ogni livello sotto la Prima Serie viene applicata una riduzione di 3 punti
all'overall base dei sei profili.

## Tour iniziale

Il tour è facoltativo, interrompibile e riprendibile. Le ricompense possono
essere riscosse una sola volta e sono registrate sul server.

| Passaggio | Ricompensa |
| --- | ---: |
| Dashboard | €1.000 |
| Squadra | €1.000 |
| Scheda giocatore | €2.000 |
| Salvataggio formazione | €3.000 |
| Campionato | €1.000 |
| Salvataggio allenamento | €3.000 |
| Accademia | €2.000 |
| Mercato | €2.000 |
| Finanze | €1.000 |
| Ritorno alla Dashboard | €1.000 |
| Bonus completamento | €3.000 |

Totale ottenibile: **€20.000**. Con la baseline economica corrente un manager
che completa tutto il tour passa quindi da €100.000 a **€120.000** e riceve il
badge permanente **Nuova Avventura**, con data di ottenimento e senza vantaggi
competitivi ulteriori.

Il tour non deve obbligare il manager a comprare, vendere, offrire o promuovere
giocatori.
